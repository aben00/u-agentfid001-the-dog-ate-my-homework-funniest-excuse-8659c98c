One original one-line excuse, in a dog's own voice, for the homework it just
ate. The dog was told "the dog ate my homework" is a bad excuse — so it ate
the homework to make the excuse a true one. Dog logic, no embarrassment, and
the twist lands on the last word.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22) writes the excuse deterministically to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`), self-checks the gate (one line, 1–200
characters by code-point count, no control characters, no edge whitespace),
reads it back with strict UTF-8 decoding and verifies it byte-for-byte.
